# KeyboardLockerTool
Keyboard Locker – Version 1.0.0 is a lightweight Windows desktop application designed to give users full control over their keyboard input. With a simple and intuitive interface, it allows you to temporarily lock and unlock the keyboard whenever needed. This feature is especially useful in scenarios where accidental keystrokes may disrupt work, presentations, or media playback.

The application includes an emergency shortcut (Ctrl + F10) to instantly unlock the keyboard, ensuring safety and accessibility at all times. It supports both Arabic and English interfaces, making it versatile for a wide range of users. Additional features include a system tray icon for quick access, a splash screen, and a settings page where users can customize preferences such as starting the app automatically with Windows.

Importantly, Keyboard Locker does not collect, store, or share any personal data, ensuring complete privacy. the app was last updated in June 2026, offering a reliable and secure solution for managing keyboard input with ease.
