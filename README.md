# KeyboardLockerTool
KeyboardLocker is a lightweight Windows app that lets users lock/unlock keyboard. Features include Ctrl+F10 emergency shortcut, Arabic/English interface, settings, and auto-start. No data is collected. التطبيق خفيف يسمح بقفل/فتح لوحة المفاتيح. يشمل اختصار  Ctrl+F10، واجهة عربية/إنجليزية، صفحة إعدادات وخيار بدء التشغيل مع ويندوز. لا يجمع أي بيانات.
